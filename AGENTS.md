# Portfolio Project

## Project Type

This is a personal developer portfolio built with vanilla:

- HTML
- CSS
- JavaScript

Do NOT migrate the project to:
- React
- Vue
- Next.js
- Tailwind
- Bootstrap
- other UI frameworks

Keep the existing architecture unless there is a strong technical reason
to change it.

## Goal

This portfolio should feel like a personal digital studio and engineering
journal rather than a generic developer portfolio template.

The website should communicate:

1. Strong engineering fundamentals
2. Real-world development experience
3. Full-stack capability
4. Curiosity and experimentation
5. Strong visual taste

The website is primarily intended for:

- recruiters
- engineering managers
- developers
- potential collaborators

## Design Direction

Use Hallmark when making visual design decisions.

Prefer:

- editorial layouts
- asymmetric compositions
- strong typography
- intentional whitespace
- visual storytelling
- distinctive navigation
- subtle motion
- meaningful interactions
- strong project presentation
- responsive-first design

Avoid:

- generic SaaS landing pages
- generic centered hero sections
- purple AI gradients
- excessive glassmorphism
- excessive rounded cards
- 3-column feature-card layouts
- generic "developer portfolio" templates
- unnecessary animations
- visual clutter
- overuse of gradients

## Technical Constraints

Preserve:

- vanilla HTML
- vanilla CSS
- vanilla JavaScript
- existing pages
- existing URLs
- existing analytics
- existing GTM/GA4 events
- existing blog functionality
- existing external integrations

Do not rewrite working functionality simply to change the UI.

## Development Principle

Before modifying the UI:

1. Inspect the existing codebase.
2. Understand the current information architecture.
3. Run a Hallmark design audit.
4. Identify the highest-impact visual problems.
5. Propose the new visual direction.
6. Implement incrementally.
7. Test desktop and mobile.
8. Verify existing JavaScript functionality.
9. Verify analytics events.
10. Perform a final Hallmark audit.

The goal is not to make the website "prettier".

The goal is to create a distinctive visual identity that feels intentionally
designed by a developer with strong taste.
